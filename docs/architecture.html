Core idea: 1-D temporal convs (dil 1/2/4/8) run over the full time axis while freq is squeezed into sub-bands, then a residual is broadcast back across all freq bins. Much lighter (30k vs 98k) — the V2 winner.

Head training rules

Command head — class-weighted CE, w_c = 1/n_c (fixed intents 3.15×, OOS 5.21×, slotted ≈1×)
Slot heads — plain CE (already balanced: 333 train / 141 test per value), only active for that intent's clips
Slot tail slice — value is the last spoken word; slot heads read the final 2.0 s (1.0 s live silent tail + full slot value — 10-02 amendment)
Input feature — locked: 3.0 s / 80-mel / 150-frame; baked into the weights, cannot change per-arch
